আমি একটা অফলাইন প্রাইভেট ওয়েব অ্যাপ বানাতে চাই। শুধু আমি নিজে ব্যবহার করব। কোনো সার্ভার, কোনো ক্লাউড, কোনো লগইন লাগবে না।

### মূল ফিচার:
1. অ্যাপটি সম্পূর্ণ অফলাইন চলবে এবং মোবাইলের লোকাল ফাইল সিস্টেম ব্যবহার করবে (বড় বড় ভিডিও থাকবে বলে IndexedDB-তে কপি করবে না, শুধু File/Directory handle বা Object URL ব্যবহার করবে)।
2. দুইটা মূল সেকশন থাকবে:
   - ভিডিও সেকশন
   - ফটো সেট সেকশন

3. লেআউট অপশন (দুটোই সাপোর্ট করো, সেটিংস থেকে চেইঞ্জ করা যাবে):
   - অপশন A: উপরে ভিডিও গ্রিড, নিচে ফটো সেট গ্রিড
   - অপশন B: উপরে ফটো সেট গ্রিড, নিচে ভিডিও গ্রিড

4. ভিডিও:
   - আপলোড করার সময় আমি নাম দিয়ে দেব।
   - বাংলা সাবটাইটেল (.vtt বা .srt) যোগ করার অপশন থাকবে (আমি নিজে সাবটাইটেল ফাইল দিয়ে দেব)।
   - থাম্বনেইল অটো জেনারেট হবে (ভিডিওর প্রথম ফ্রেম থেকে)।
   - ভিডিও প্লেয়ারে সাবটাইটেল দেখাবে।
   - বড় ভিডিও সাপোর্ট করতে হবে।

5. ফটো সেট:
   - আপলোড করার সময় আমি সেটের নাম দিয়ে দেব।
   - একটা সেটের ভিতরে একাধিক ফটো + ভিডিও থাকতে পারবে।
   - সেটের কভার থাম্বনেইল অটো জেনারেট হবে (প্রথম ফটো বা ভিডিও থেকে)।
   - সেট খুললে ভিতরে ফটো ও ভিডিও সুন্দর গ্রিড/ম্যাসনরি লেআউটে দেখাবে।
   - ফটোগুলো বড় করে সুন্দরভাবে দেখা যাবে (লাইটবক্স স্টাইল)।

6. আপলোড ফ্লো:
   - “নতুন ভিডিও যোগ করো” বাটন → ফাইল সিলেক্ট + নাম + সাবটাইটেল (অপশনাল)
   - “নতুন ফটো সেট তৈরি করো” বাটন → সেটের নাম + একাধিক ফটো/ভিডিও সিলেক্ট
   - থাম্বনেইল সবসময় অটো জেনারেট হবে।

7. ডিজাইন:
   - ডিপ ব্ল্যাক ব্যাকগ্রাউন্ড, সফট গোল্ড/শ্যাম্পেন অ্যাকসেন্ট।
   - বড় রাউন্ডেড কার্ড, স্মুথ অ্যানিমেশন, মোবাইল-ফার্স্ট।
   - খুব ক্লিন ও লাক্সারি ফিল।

8. টেকনিক্যাল রিকোয়ারমেন্ট:
   - Progressive Web App (PWA) হতে হবে যাতে হোম স্ক্রিনে অ্যাড করা যায়।
   - সম্পূর্ণ অফলাইন কাজ করবে।
   - File System Access API + fallback হিসেবে <input type="file"> ব্যবহার করবে।
   - থাম্বনেইল Canvas দিয়ে জেনারেট করবে।
   - ভিডিও প্লেয়ারে WebVTT সাবটাইটেল সাপোর্ট থাকবে।
   - কোনো ব্যাকএন্ড নেই। সব ডাটা লোকাল (IndexedDB-তে শুধু মেটাডাটা + থাম্বনেইল রাখবে, আসল মিডিয়া ফাইল লোকাল ফাইল সিস্টেমে থাকবে)।

আগে আমাকে কনফার্ম করো যে তুমি রিকোয়ারমেন্ট বুঝেছ, তারপর স্টেপ বাই স্টেপ বিল্ড শুরু করো। প্রথমে প্রজেক্ট স্ট্রাকচার + UI ডিজাইন প্ল্যান দাও।
